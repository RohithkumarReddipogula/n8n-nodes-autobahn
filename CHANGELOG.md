# Changelog

## 0.1.0

- First release.
- Road resource: Get Many (list all Autobahn road IDs).
- Traffic Event resource: Get and Get Many for roadworks, warnings, closures, charging stations, lorry parking and webcams.
- Several roads per request, Only Blocked and Exclude Future filters, Return All / Limit.
- Simplify option that flattens the raw API response into clean fields for downstream nodes and AI agents.
- Usable as a tool by the n8n AI Agent node.
